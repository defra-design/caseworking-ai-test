Defra header

A fully custom internal header used on all casework pages in place of the standard GOV.UK or MOJ header.

The header uses the .defra-internal-header class with a 8px solid bottom border in Defra brand green (#00a33b). It includes the Defra logo on the left and the service name on the right.

Do not replace this with a standard GOV.UK or MOJ header. All changes to this component should remain within the .defra-* classes in application.scss.

Title alignment

By default the service name sits immediately to the right of the logo. Two modifiers move it, both set from the page rather than hard-coded into the include:

  • --centred ({% raw %}{% set headerTitleCentred = true %}{% endraw %}) centres the title inside the space left over beside the logo. Because the logo takes the first third of the bar, the title lands right of the true middle.
  • --centred-full ({% raw %}{% set headerTitleFullCentred = true %}{% endraw %}) centres it on the whole bar. It lifts the title out of the header's table row and stretches it across the container, so it stays centred whatever width the logo cell ends up. Set it alongside headerTitleCentred, which stays as the narrow-screen behaviour.

Key classes

Class Purpose
.defra-internal-header Outer wrapper — sets padding and the 8px green bottom border
.defra-logo Logo container — green left border, sets min-width for alignment
.defra-logo__link Renders the Defra PNG logo via CSS ::before pseudo-element
.defra-internal-service-name Service name container — vertically centred alongside the logo
.defra-internal-service-name--centred Centres the title in the space beside the logo — set with headerTitleCentred
.defra-internal-service-name--centred-full Centres the title on the whole bar (absolute, wide layout only) — set with headerTitleFullCentred
.defra-internal-service-name__link Service name link — 21px / 24px font, no underline, black text

When to use

  • Use the default (no modifier) wherever the header reads as a service banner and the title belongs next to the logo.
  • Use --centred-full on a scheme-specific area whose header carries a short name — it reads as the title of the whole page rather than a label hanging off the logo.
  • Set both modifiers together: --centred carries the narrow-screen layout, where the logo stacks above and the title centres normally.

When not to use

  • Don't use --centred-full with a long service name — the title is taken out of the flow, so a wide one can run under the logo instead of wrapping beside it.
  • Don't add either modifier to a header that carries anything else in the bar (navigation, a sign-out link) — the absolute title would sit over it.
  • Don't reach for it to nudge alignment on one page. It is an area-wide decision, so every page in that area should set the same flag.

Customisation in this prototype

The header is a table at wide widths: the logo takes a 33.33% cell and the service name fills the rest, which is why plain centring sits right of the middle. --centred-full gives .defra-internal-header .govuk-width-container a positioning context and absolutely positions the title across it, vertically centred with translateY(-50%). It is scoped to min-width: 48.0625em so the stacked narrow layout is untouched.

Where does this occur

  • Agreement — default alignment
  • Woodlands entitlements — --centred
  • GTIF caselist — --centred
  • Woodland grant applications (v2) — --centred-full
  • Woodland v2 case console — --centred-full
