{# Land parcel references for the conditional review tasks, taken from the same data as the Calculations page so a task lists exactly the parcels whose checks carry a "Task" tag: {% import "GrassMVP/includes/_case-task-parcels.html" as tp %} {% set lps = tp.refLPs("ponds", data.mvpCalcVariant) %} kind: "sssi" (parcels with an SSSI Task check), "sssiHistoric" (in an SSSI or with historic features — task A), "buildings" (HEF1), "ponds" (WBD1), "any" (every parcel in the case).
